# Palette's Journal

## Design System Accessibility Patterns
- **Colors:** Blue-600 (`#2563eb`) is the primary active/focus color. Slate-600 (`#475569`) is used for secondary text.
- **Focus:** `focus-visible:ring-2 focus-visible:ring-blue-500` is the standard focus ring.
- **Motion:** Transitions are generally `duration-200` or `duration-300`.
- **Feedback:** `role="status"` and `aria-live="polite"` should be used for dynamic content updates (like charts loading or empty states).
