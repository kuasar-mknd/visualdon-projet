# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of our systems seriously. If you have found a security vulnerability, please submit a report to us as described below.

### How to Submit a Report

Please send an email to [security@kuasar.xyz](mailto:security@kuasar.xyz) with the following details:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

We will acknowledge your report within 48 hours and will strive to keep you updated on our progress.

### What to Expect

- You can expect a civil conversation and a collaborative effort to resolve the issue.
- We will prioritize the fix based on the severity of the vulnerability.
- We may ask for your help in verifying the fix.

## Security Practices

We follow standard security practices:
- **Dependency Management:** We regularly update our dependencies.
- **Static Analysis:** We use linting and static analysis tools.
- **CSP:** We enforce a strict Content Security Policy.
- **Sanitization:** We sanitize inputs and avoid dangerous patterns like `dangerouslySetInnerHTML`.
